Кино на двоих — готовая сборка v1.0.0

Что внутри: сервер, собранный фронт (dist), скрипты обновления каталога,
готовая модель данных (data/model) и node_modules. Сборку из исходников
делать не нужно, npm install не нужен.

Что нужно: Node.js 18 или новее — https://nodejs.org

БЫСТРЫЙ СТАРТ (Windows):
  двойной клик по КИНО.bat — он сам проверит Node.js, попросит ключ TMDB,
  спросит про постеры и запустит сервер. Готово.

Ручной запуск:
- Windows: двойной клик по start-kino.vbs (порт 80, окна нет, упал — поднимется сам)
- macOS:    bash КИНО.bat не сработает — используйте терминал:
            PORT=3000 node server/index.js
Остановка: закрыть окно сервера (или stop-kino.cmd на Windows).
Порт меняется переменной окружения PORT.

СЛУЖБА (чтобы сервер работал сам, без ручного запуска):
- Windows: запустите deploy\install-service-windows.bat
           (права администратора запросит сам). Сервер стартует при включении
           компьютера, перезапускается при падении, работает без входа в систему.
           Убрать: deploy\remove-service-windows.bat
- macOS:   в Терминале из папки приложения:
           bash deploy/install-service-mac.sh
           Сервис стартует при входе, перезапускается при падении, раз в неделю
           сам обновляет каталог. Убрать: bash deploy/remove-service-mac.sh
           Логи: data/kino.log и data/kino.err.log

Постеры в сборку не входят (~1 ГБ). Без них сервис работает: там, где фильм
сопоставлен с Кинопоиском, показывается его обложка. Чтобы скачать постеры:
1. Получите ключ на themoviedb.org (v3 key или v4 read token)
2. Положите его в файл data/tmdb.key
3. Выполните npm run tmdb и перезапустите сервер
(КИНО.bat делает шаги 2-3 сам.)

Данные: база пользователей создастся сама при первом запуске (data/db.json).
Все оценки живут в этом файле; сервер сам делает ежедневные резервные копии
в data/backup/auto (последние 14).

Обновление каталога (новые фильмы и сериалы): npm run tmdb, затем npm run enrich,
перезапуск сервера. В режиме службы перезапуск не нужен: сервер обновится сам.

Проверка точности рекомендаций на ваших оценках: npm run backtest.

Источники данных (некоммерческое использование):
- MovieLens (GroupLens) — матрица похожести фильмов
- TMDB — фильмы, сериалы, постеры
- Wikidata — русские названия и ID Кинопоиска

Сервис не защищён паролем — используйте только в своей локальной сети,
не выставляйте порт в интернет.

Исходники и подробности: https://github.com/EndoTouma/kino_dvoe
