# Кино на двоих

Домашний сервис для пары: каждый отмечает, что смотрел и как оценил, а сервис подбирает фильмы, которые понравятся обоим.

Работает на домашнем ПК, открывается с телефонов в той же Wi-Fi сети.

## Как открыть

| Откуда | Адрес |
|---|---|
| С этого ПК | `http://localhost` |
| С телефона в домашней сети | `http://192.168.1.100` |

Адрес `192.168.1.100` — это IP компьютера. Чтобы он не менялся, закрепите его за ПК в списке устройств роутера. Сайт доступен, пока ПК включён и не спит.

На телефоне удобно добавить страницу на главный экран: появится иконка «Кино». На iPhone (Safari → «Поделиться» → «На экран Домой») сайт откроется как приложение, без адресной строки. На Android получится ярлык: полноценная установка требует HTTPS, которого в домашней сети нет.

## Как пользоваться

### 1. Пользователи

На стартовом экране создайте по пользователю на каждого и выберите себя. Паролей нет. Сменить пользователя — кнопка с именем справа вверху. «Настроить пользователей» — переименование и удаление (удаление стирает все оценки этого человека).

### Фильмы и сериалы

Вверху опроса и рекомендаций есть переключатель «Фильмы / Сериалы». У сериалов свой опрос, свои списки и свой «Выбор на вечер»; статусы те же. Оценки фильмов и сериалов помогают друг другу через любимые жанры, актёров и режиссёров. Поиск в «Моих фильмах» и «Вместе» ищет и то и другое.

### 2. Опрос

Сервис показывает фильмы по одному, от самых известных. По каждому один из ответов:

| Не смотрел | Смотрел |
|---|---|
| **Хочу** — поднимет фильм в рекомендациях | Оценка **1–10**, затем вопрос «Пересмотреть?» |
| **Не знаю** — просто не видел | **Хочу** — поднимет фильм в «Пересмотреть вместе» и «Показать партнёру» |
| **Не хочу** — фильм никогда не предложат паре | **Не знаю** / **Не хочу** — пересматривать не предложат |
| **Собирались** — попадает во вкладку «Планы» | |

У сериалов есть ещё два статуса: **«Смотрю сейчас»** (с номером сезона) и **«Бросил»**. Начатые сериалы показываются во вкладке «Смотрим и планы», брошенные нигде не предлагаются.

Если фильм видели, но оценивать не хочется, под цифрами есть кнопка **«Без оценки»**: дальше так же выбирается, хотите ли пересматривать.

Кнопка **«Не помню»** — для фильмов, которые видели, но не помните. Фильм считается просмотренным и не попадает в «Новое для всех», на подбор не влияет, зато может появиться во вкладках «Показать партнёру» и «Пересмотреть вместе».

Опрос подстраивается под ответы. Фильмы, о которых люди спорят (разброс оценок большой), показываются чуть раньше: один ответ о таком фильме говорит о вкусе больше. «Не хочу» и низкие оценки отодвигают похожие фильмы в конец очереди (например, остальные части той же франшизы), «Хочу» и высокие оценки подтягивают похожие ближе. То же влияет и на рекомендации.

Базовый опрос — 200 фильмов, дальше он продолжается сколько угодно. Чем больше оценок, тем точнее подбор; первые осмысленные рекомендации появляются после 20 оценённых фильмов.

- «← Вернуть предыдущий» отменяет последний ответ.
- «Найти фильм самому →» ведёт к поиску, если хочется оценить конкретный фильм, не дожидаясь его в опросе.

### 3. Что смотреть

Вверху выберите, кто смотрит (обычно оба). Вкладки:

- **Новое для всех** — фильмы, которые не видел никто из выбранных. Число справа — общий балл: учитывает прогноз для каждого и тянется к худшему из них, чтобы никто не скучал. «Хочу» от любого из вас поднимает фильм выше.
- **Новинки** — то же, что «Новое для всех», но только вышедшее за последние два года.
- **Планы** (у сериалов «Смотрим и планы») — то, что кто-то отметил «Собирались» или «Смотрю сейчас».
- **Показать партнёру** — один видел и хочет пересмотреть (или оценил на 8+, или не помнит), второй не видел.
- **Пересмотреть вместе** — видели оба, и каждый либо хочет пересмотреть, либо оценил на 8+, либо не помнит. Отметка «Хочу» в вопросе «Пересмотреть?» поднимает фильм выше.

Под фильмом написано, на какие из понравившихся вам фильмов он похож. Продолжения не предлагаются, пока кто-то из вас не видел предыдущую часть; короткометражки и документальные фильмы не предлагаются вовсе (но находятся поиском, а «Хочу» возвращает их в список).

Кнопки у фильма:

- **Посмотрели** — открывает панель, где можно сразу поставить оценку каждому.
- **Не сегодня** — прячет фильм из списка на две недели.
- **Не хочу** — убирает фильм из совместных списков навсегда.

После «Не сегодня» и «Не хочу» внизу на семь секунд появляется плашка «Отменить» на случай промаха.

Пометка «мало данных» у прогноза означает, что сервису почти не на что опереться (меньше трёх похожих оценённых фильмов, знакомых режиссёров или актёров) и цифра близка к общему рейтингу.

#### Выбор на вечер

Последняя вкладка. Один из вас нажимает «Начать», после чего оба на своих телефонах отвечают «да» или «нет» на одни и те же 12 фильмов из верха списка. Первый фильм, которому оба сказали «да», объявляется фильмом на сегодня. У второго участника на любом экране появляется плашка «Идёт выбор на вечер — ваш ход». Если совпадений нет, можно взять следующие 12.

### 4. Вместе

- Поиск сверху: найдите фильм, который посмотрели вдвоём, отметьте, кто смотрел, и поставьте оценки.
- Карточка «Совместимость вкусов»: процент совпадения, фильмы, которые любите оба, и те, где сильнее всего расходитесь. Оценки сравниваются относительно личной планки каждого, так что строгий зритель не выглядит несогласным со всем.
- Ниже — история совместных просмотров с датой и оценками. Тап по записи позволяет поправить оценки.

Если кому-то оценку не поставили, при следующем заходе он увидит напоминание «Вы посмотрели — оцените».

### 5. Мои фильмы

Все ваши ответы с фильтрами (оценённые, хочу, не хочу, все) и поиском по каталогу. Тап по фильму — изменить ответ или сбросить его.

**Моя статистика** — под поиском: сколько просмотрено, как часто какие оценки ставите, какие жанры, режиссёры, актёры и десятилетия оцениваете выше всего.

**Стоп-жанры** — там же, под поиском. Отмеченные жанры больше не предлагаются вам в опросе и не попадают в общие рекомендации.

### Карточка фильма

Тап по любому постеру открывает описание, дату выхода, страну, режиссёра, актёров, бюджет и ссылку на Кинопоиск. Закрывается крестиком или тапом мимо.

## Обслуживание

Все команды выполняются в папке проекта.

### Запуск и остановка

Сервер стартует сам при входе в Windows (ярлык `Kino.lnk` в автозагрузке, `Win+R` → `shell:startup`).

| Действие | Как |
|---|---|
| Запустить вручную | двойной клик по `start-kino.vbs` |
| Остановить | двойной клик по `stop-kino.cmd` |
| Перезапустить | диспетчер задач → завершить `node.exe`: через 5 секунд сервер поднимется сам |
| Посмотреть лог | `data\kino.log` |

Скрипт запуска следит за сервером: если тот упал, через 5 секунд запускает заново. Поэтому простое завершение `node.exe` сервер не останавливает, а перезапускает; для остановки есть `stop-kino.cmd`.

Перезапуск нужен после обновления данных (`npm run tmdb`) и после правок в папке `server`.

### Резервная копия

Все пользователи и оценки лежат в одном файле: `data\db.json`. Сервер сам делает его копию раз в день и хранит последние 14 в `data\backup\auto`. Это защищает от ошибок и случайных удалений, но не от поломки диска: изредка копируйте файл и на другой носитель. Для восстановления остановите сервер, верните файл на место и запустите снова.

### Обновление каталога (новые фильмы)

```
npm run tmdb
```

Сервер делает это сам раз в неделю: докачивает новые фильмы и сериалы, обновляет рейтинги свежих релизов, затем перезапускается, когда сайтом 10 минут никто не пользуется. Ход обновления пишется в `data\update.log`. Команда выше нужна, только если хочется обновить каталог немедленно (после неё выполните `npm run enrich` и перезапустите сервер).

Скрипт докачивает из TMDB новые фильмы, сериалы, описания и постеры. Уже скачанное пропускает, поэтому повторный запуск быстрый; если оборвался — просто запустите ещё раз. После завершения перезапустите сервер.

- Ключ TMDB читается из файла `data\tmdb.key`.
- TMDB должен быть доступен с ПК: на роутере для доменов `themoviedb.org` и `tmdb.org` указан DNS-сервер `9.9.9.9`.
- Постеры хранятся в `data\posters`.

### Сеть

- В брандмауэре Windows есть правило «Kino 80»: входящие на порт 80 только из локальной сети.
- Сервис не защищён паролем. Не открывайте его в интернет.

## Если что-то не работает

| Симптом | Что проверить |
|---|---|
| С телефона не открывается | ПК включён и не спит; телефон в домашнем Wi-Fi, а не в гостевой сети и не на мобильном интернете; VPN на телефоне выключен |
| Раньше открывалось, теперь нет | у ПК сменился IP: посмотрите новый командой `ipconfig` или закрепите адрес на роутере |
| Не открывается и с ПК | сервер не запущен: запустите `start-kino.vbs`, загляните в `data\kino.log` |
| Нет постеров | не выполнен `npm run tmdb` или сервер не перезапущен после него |
| Нужного фильма нет в поиске | в каталоге только фильмы с достаточным числом голосов на TMDB; обновите каталог |
| Рекомендации странные | мало оценок: пройдите опрос дальше, нужно хотя бы 20–30 оценённых фильмов у каждого |

## Как устроен подбор

- Для 8000 самых оценённых фильмов MovieLens (до 2023 года) прогноз строится по оценкам 200 тысяч его пользователей: «тем, кто оценил фильмы как вы, понравилось вот это», с поправкой на ваших любимых режиссёров, актёров и темы (ключевые слова TMDB).
- Для более новых фильмов и для сериалов таких данных нет, прогноз грубее: рейтинг TMDB, похожие фильмы, режиссёры, актёры и жанры. Поэтому новинки реже попадают в верх общего списка; для них есть вкладка «Новинки», а отметка «Хочу» поднимает фильм где угодно.
- Статусы без оценки («хочу», «не хочу») учитываются, но втрое слабее настоящей оценки.

### Насколько прогнозу можно верить

```
npm run backtest
```

Скрипт по очереди прячет каждую вашу оценку, предсказывает её по остальным и печатает среднюю ошибку в баллах для каждого пользователя, рядом с двумя наивными способами («средняя оценка фильма» и «ваша средняя оценка»). Ничего не меняет. Если ошибка модели не меньше наивной, настройки в `server/recommender.js` (`PARAMS`) пора пересмотреть.

## Для разработки

| Команда | Что делает |
|---|---|
| `npm run dev` | сервер и фронт с автообновлением (`http://localhost:5173`) |
| `npm run build` | собрать фронт в `dist` (сервер раздаёт его сразу, без перезапуска) |
| `npm start` | запустить сервер в консоли (порт из переменной `PORT`, по умолчанию 3000) |
| `npm run backtest` | проверить точность прогнозов на ваших оценках |
| `npm run model` | пересчитать модель из `data\raw\ml-32m` (переменные `KINO_N`, `KINO_SAMPLE`, `KINO_MODEL`) |
| `npm run enrich` | русские названия и ID Кинопоиска из Wikidata (запускать после `npm run tmdb`, чтобы охватить новые фильмы) |

Структура: `server/` — API и подбор, `web/` — интерфейс, `scripts/` — подготовка данных, `data/` — база, модель и постеры, `deploy/` — запуск на роутере (`S99kino`) и установка сервера в автозагрузку Windows/macOS (`install-service-*`).

## Развёртывание с нуля

1. `npm install` — зависимости.
2. Скачайте датасет [MovieLens 32M](https://grouplens.org/datasets/movielens/32m/) и распакуйте архив в `data/raw/`, чтобы получилось `data/raw/ml-32m/`.
3. `npm run model` — собрать модель (`data/model/`, ~64 МБ).
4. Получите ключ TMDB (v3 key или v4 read token) на themoviedb.org и положите его в файл `data/tmdb.key`.
5. `npm run tmdb` — скачать фильмы, сериалы, описания и постеры (долго, но перезапускаемо: скачанное пропускается).
6. `npm run enrich` — русские названия и ID Кинопоиска из Wikidata.
7. `npm run build` — собрать фронт.
8. `npm start` — сервер на `http://localhost:3000` (порт задаётся переменной `PORT`). На Windows без консоли и с автоперезапуском — `start-kino.vbs`.

Папка `data/` в репозитории не хранится: база пользователей появится сама при первом запуске, модель и каталог собираются шагами выше.
